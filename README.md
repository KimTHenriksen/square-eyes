# Square Eyes

Square Eyes is a website where you can look at different movies and buy movies from independent filmmakers.

[View Square Eyes](https://kimthenriksen.github.io/square-eyes/)

## Description

Square Eyes was my first website project and was made as an HTML & CSS course assignment at Noroff.

On the website you can look through different movie categories, and read more about the movies.
There are also pages for the categories, my videos, cart, checkout, about, contact and support.

For Portfolio 1, I went back to the project and made some changes based on the feedback I got when I first submitted it.

## Features

- Responsive design
- Navigation menu
- Product details
- Different movie categories
- Cart and checkout
- My videos
- About and Contact pages
- Support page for donations

## Improvements

For Portfolio 1 I made some improvements to the project:

- Changed the navigation so it works better on smaller screens
- Fixed the logo so it does not get squashed
- Fixed HTML validation errors
- Fixed the headings so the pages have one main heading
- Added CSS variables for colors I use several times
- Fixed the footer on pages with less content
